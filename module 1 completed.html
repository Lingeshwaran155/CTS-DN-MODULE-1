01 / Setting Up Bootstrap 5

1.1 Link Bootstrap 5 via CDN

Head snippet (already applied to this page)

<!-- Bootstrap 5 CSS CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
      rel="stylesheet">

<!-- Bootstrap 5 JS Bundle CDN -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
</script>
This entire page is served via CDN — Bootstrap is active!

02 / Bootstrap Structure & Files

2.1 Downloaded directory structure explained
bootstrap/
├── css/
│   ├── bootstrap.min.css       ← Minified full CSS
│   ├── bootstrap.css           ← Full unminified CSS
│   ├── bootstrap-grid.css      ← Grid-only build
│   ├── bootstrap-reboot.css    ← Reboot/normalize only
│   └── bootstrap-utilities.css ← Utility classes only
├── js/
│   ├── bootstrap.bundle.min.js ← JS + Popper.js bundled ✓ recommended
│   ├── bootstrap.min.js        ← JS only (needs separate Popper)
│   └── bootstrap.esm.min.js    ← ES Module version
└── icons/
    └── (Bootstrap Icons SVG sprite)
2.2 Include bootstrap.bundle.min.js
<!-- Place before </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
<!-- bundle includes Popper.js — needed for dropdowns, tooltips, popovers -->
bundle.min.js includes Popper.js so you don't need a separate Popper CDN tag.

19 / Customization with Sass

19.1 Set up Bootstrap 5 with Sass via npm
npm init -y
npm install bootstrap sass

# Project structure
my-project/
├── scss/
│   └── custom.scss     ← your Sass entry point
├── node_modules/
└── dist/               ← compiled output

# custom.scss
@import "../node_modules/bootstrap/scss/bootstrap";

# Compile command (add to package.json scripts):
# "build-css": "sass scss/custom.scss dist/css/custom.css"

npm run build-css
19.2 Override $primary color & $border-radius in _variables.scss
// scss/custom.scss

// 1. Override Bootstrap default variables BEFORE importing Bootstrap
$primary:        #e84d1c;      // your brand orange-red
$secondary:      #1c6fe8;      // your brand blue
$border-radius:  0.75rem;      // more rounded corners
$font-family-base: 'DM Sans', sans-serif;

// 2. Required Bootstrap imports
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/variables-dark";
@import "../node_modules/bootstrap/scss/maps";
@import "../node_modules/bootstrap/scss/mixins";
@import "../node_modules/bootstrap/scss/root";

// 3. Optional: import only what you need
@import "../node_modules/bootstrap/scss/grid";
@import "../node_modules/bootstrap/scss/buttons";
@import "../node_modules/bootstrap/scss/utilities";

// 4. Or import everything
// @import "../node_modules/bootstrap/scss/bootstrap";
Key rule: Always set your override variables before @import "bootstrap/scss/variables" so Bootstrap picks them up.
